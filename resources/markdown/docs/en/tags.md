Categories say what kind of money a transaction is: **Food**, **Housing**, **Salary**. Tags say anything else you want to follow, across categories: a trip, a person, a project, a renovation. A dinner and a hotel on the same holiday have different categories and the same tag.

## Creating tags

Open **Tags** and choose **Create tag**. A tag only has a name, which must be unique within the team. Tags are free and unlimited on every plan.

## Tagging transactions

Add tags to an income, an expense or a transfer with the **Tags** option while recording it, or later with **Edit**. A transaction can carry as many tags as you like. Tags added to a transfer apply to both of its sides and to its fees.

On the **Transactions** page, the **Tags** filter under **More filters** lists the transactions that carry a tag.

## Deactivating a tag

When a tag has served its purpose, choose **Deactivate** from its menu instead of leaving it in every picker. A deactivated tag:

- is no longer offered when recording or editing a transaction;
- stays on every transaction that already carries it;
- can still be used to filter the **Transactions** page.

Choose **Activate** to offer it again.

## Tags in the monthly report

The **Monthly** page breaks each currency down **By category** and **By tag**. A transaction counts under each of its tags, so the tag rows can add up to more than the month's totals. Untagged transactions are grouped on a row of their own.

## Budgets on a tag

With Pro, a tag can carry a monthly budget in each currency, set straight from the tag's form. See [Budgets](/en/docs/budgets).
